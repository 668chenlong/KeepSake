# KeepSake

KeepSake is a desktop library and reader for personal documents, designed by Navi Studio.

Choose a folder as your library. KeepSake opens .nposter books in its reader. Other files can be opened in the macOS app you choose.

## Bilingual reading

Open a bilingual .nposter to read two aligned columns. Click a sentence to hear its audio. Each language has its own timing, so switching languages takes you to the matching sentence.

- W / S moves to the previous or next sentence in the current language.
- Left / Right switches between the paired sentences.
- A / D adjusts playback speed, G replays the sentence, and T switches between continuous and single-sentence playback.
- F records a take and R plays it back. Takes are kept in the current reading session.

The current build is a local preview for Apple Silicon Macs.
